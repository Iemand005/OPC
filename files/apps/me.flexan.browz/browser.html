Change proxy URL

Change the default proxy URL. The proxy must be implemented to support Browz and the path must end with '/'.


Redirect big files

Some files that are loaded through the proxy are too big to be sent modified. Enabling this option will fetch the big resources from the original source rather than through the proxy. Note that CORS issues may arrise. Applying this setting will immediately reload the page.

Attention!

A big JavaScript file has failed to load because it is too big. The site may not function without it. It is recommended to turn on the 'Redirect big files' setting.
